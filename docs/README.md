# Important note regarding docs in this folder

The entirety of the *content* of this book is authored by me, Oliver JL Renwick. The photos and imagery, likewise, are for better or worse, taken by me.

*However*, the coding and software tools involved in producing both the website version and the, hopefully eventual, print version, as well as any other subsystems I may create -- version tracking, markdown-based neural graphs, heat maps, etc -- will be largely the work of LLMs. Specifically, at least up until the initial commit date of this file, I have primarily used GPT... 4o, I believe.

**This README was typed by human hands. The other .md files in this directory will largely be the product of an LLM; this is beneficial to me, to help keep a record of how the (fairly complex tbh) build system works, as well as keeping track of all the changes and decisions involved in those changes over time.**

This project began with a very paranoid approach to code, focusing on maximal compatibility, minimal dependencies; the idea was to build something that could be e.g. run as a dapp or a permadapp on the most minimal hardware / environment possible.

I'm feeling less paranoid now, and more like I actually want to build the thing I want to build. As such, well... "you can just do things"
